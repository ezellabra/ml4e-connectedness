\section{Data and Code Availability}
% Budget: 0.5 pages.
The data (weekly ETF returns) and the full code are available at \todo{repository URL}. The pipeline is written in Python; NETS and FNETS are estimated in R (packages \texttt{nets} 0.9.1 and \texttt{fnets} 0.1.6) through a command-line bridge. All parameters are in \texttt{config.yaml} and the whole analysis is reproduced with \texttt{make all} (or \texttt{python run\_all.py}).
